# 统一日活服务

2026-09-28。维护入口移至独立私有仓库 `Thankyou-Cheems/SiguaAnalytics`（本地相邻目录 `D:/Dev/SiguaAnalytics`）。本页保留产品边界及迁移依据，实施和操作步骤以该仓库为准。

一个 Go 进程、每产品一个 SQLite 文件；无需城市库、Redis、消息队列或数据库守护进程。产品独立事务、密钥、Origin、指标与渠道白名单。提交完成后才确认接收，短事务完成去重和计数。每产品默认限制 100 次请求/秒、最多 8 个处理中请求，超限返回 429。

| 产品 | 口径 | 接入 |
| --- | --- | --- |
| Armor 两版 | UTC 日内按 IP 去重，沿用旧 HMAC 与加密密钥 | 原有 `/__analytics/dau` 和管理员日活总览不变 |
| Bomana App/Calculator | 保留现有每日安装 HMAC；App Edition 首次上报，Calculator 渠道独立、产品总量去重 | `/api/v2/metrics/{events,daily,history}`；旧接口退役 |
| Bomana App 启动 | 每次成功初始化一次；刷新/重新打开算新启动，Launcher、计算器、失败初始化不计 | 随机事件 ID 去重；最多一次客户端重试；按发生时间 UTC 日期计数 |
| Calc | 独立产品密钥的 IP 日活 | 独立命名空间；不从地图查询、坐标或健康探测推算用户日活 |

各产品数字不能相加后称为去重人数。IP 或安装身份都不是严格的人数统计。公开汇总不返回 IP、令牌、事件 ID 或账号。Bomana 表不记录请求 IP/UA。

原始每日身份与启动去重记录保留 30 个 UTC 日；聚合日总数长期保留。新启动指标有明确起始日，之前返回 `null`。用户已明确旧 Bomana 完全退役，因此原方案中兼容旧统计接口、混合 `max(legacyDau, anonymousDau)` 等要求取消；旧事件和原始口径汇总只做受限历史归档。

Armor 的普通部署不再构建、打包或重启统计容器。生产统计栈迁至 `/opt/stacks/sigua-analytics`，保持内部 `sigua-analytics:8081` 地址。首次迁移暂停旧写入、创建一致性副本、导入并逐日比较后转交入口；后续程序回滚保留当前数据库，不能恢复旧数据库丢掉新记录。旧嵌入式统计版本不属于普通 Armor 页面回滚范围。

## 隔离候选证据

2026-09-28 服务器候选使用主机内历史副本，未下载原始 IP、令牌或密钥：

- Armor 75 个日期、每日数量之和 934，数据库和管理员 HTTP 结果逐日一致。
- Bomana 181 个日期/渠道汇总完全一致；产品每日数量之和 806，旧事件 26,301 条单独完整归档。
- 合成双产品、4 路并发、1,000 次事务写入：约 860 次/秒，P50 4.23 ms、P95 6.75 ms；重启后重放同一批请求没有重复增长。这是短时隔离试验，不是长期容量承诺。
- 候选空闲 RSS/PSS 11,280/11,276 KiB，负载后 19,076/19,072 KiB（含额外两个测试产品）。迁移前两个正式统计进程合计 RSS 34,876 KiB。城市库的先前节省未重复计入。
- Go 验证覆盖身份连续性、产品隔离、加密、并发去重、跨午夜重试、历史缺失语义、磁盘写入失败、重启、30 日清理；Bomana 单测与浏览器计算器验证通过，且未向线上发送合成信号。
