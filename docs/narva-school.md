# Narva 学校功能维护

学校显示与碰撞查询分别加载。Wiki 的 `school-scene.json`、`school-display.json` 用于显示，`native-query.json` 用于计算。查看载具时只加载显示，进入驾驶员或炮手视角后加载查询；查询失败时暂停开火，再次进入操作视角可以重试。

载具检查默认使用降低亮度、对比度和饱和度的学校背景，仅调整学校材质，载具照明和共享颜色数据保持原样。左侧“背景”可切换“纳尔瓦学校 / 经典网格”，选择保存在当前浏览器。网格沿用 0.5 米间隔并与参照士兵脚下刻度对齐，不改变模型尺寸或命中空间。

驾驶员和炮手操作时始终显示原有学校场景，防止隐藏实际参与查询的障碍物；退出操作后恢复所选检查背景。切换背景只更新场景可见性与学校材质参数，不重新加载载具或清除命中记录。

坐标转换、组件与 Actor 身份、材质绑定、查询精度和缓存生命周期属于运行合同。修改后运行 `npm run check`，并在浏览器验证操作视角、载具武器切换和学校命中。不得用显示模型替代计算数据。

当前功能提供静态学校范围内的碰撞、穿透层和末层入射伤害。越出覆盖范围时结束未确认结算；建筑血量、破坏、范围爆炸与动态目标对战尚不属于此功能。

先验证 Wiki 接口与依赖，再按[部署流程](deployment.md)切换 Armor。研究依据、提取与制作方法、对照记录和历史试错统一保存在私有 Research。
